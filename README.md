# Study Anything

> 把「陌生领域速通」做成一条可复用流程的 Agent Skill。  
> **不产出总结，产出判断力**：先画地图，再一道一道验证你到底站在哪。
>
> *An agent skill that maps an unfamiliar field before teaching it — five mental models, three real debates, then one diagnostic question at a time.*

---

## 它解决什么

大多数人学新领域的路径是：收藏 20 篇「一文读懂」→ 读完 → 记住一堆名词 → 一开口就露馅。

问题不在努力程度，在顺序。**先有结构，才谈得上理解；先能被质问，才谈得上掌握。**

这个 Skill 把顺序反过来，固定产出四样东西：

| 产出        | 是什么                                       |
| --------- | ----------------------------------------- |
| **源台账**   | 哪些材料真读进来了，哪些没有，缺口在哪                       |
| **概念地图**  | 概念清单 + 依赖边（`A ← B`）+ 学习梯队                 |
| **5 + 3** | 5 个核心心智模型（每个带失效条件）+ 3 个关键分歧（区分真争议 / 工程取舍） |
| **答题台账**  | 每道题的答案、错误类型、薄弱点、下次复习时间                    |

结业标准不是「讲得出」，而是：**能就该领域一个仍有争议的问题，说出双方最强论点、自己的立场和裁决变量。**

## 安装

仓库本身就是技能目录，clone 下来就算装好了——没有依赖、没有构建、没有"安装"这个动作。

| 环境                  | 目标路径                                         | 怎么验证                                     |
| ------------------- | -------------------------------------------- | ---------------------------------------- |
| DeepSeek Harness    | `$DSH_HOME/skills/`（默认 `~/.dsh/skills/`）     | 对话框输入 `/`，在「技能」组里看到 `study-anything` |
| Claude Code         | `~/.claude/skills/`                          | `/skills`                                |
| WorkBuddy           | `~/.workbuddy/skills/`                       | 技能列表                                     |
| 项目级（只对单个仓库生效，优先级最高） | `<项目>/.dsh/skills/` 或 `<项目>/.claude/skills/` | 同上                                       |

macOS / Linux：

```bash
git clone https://github.com/WCNNB/study-anything.git ~/.dsh/skills/study-anything
```

Windows（PowerShell）：

```powershell
git clone https://github.com/WCNNB/study-anything.git "$env:USERPROFILE\.dsh\skills\study-anything"
```

> ⚠️ **不要用「添加插件」入口装。** 技能不是插件包，那个入口只认 `package.json` + 代码入口，会报「该路径不存在或不是有效的插件包」。技能只需要放到扫描目录里。

## 用法

直接说你要学什么：

```
用 study-anything 带我入门 密码学
我下周要跟甲方聊等级保护，帮我把这块搞明白
这些资料我看不完，帮我压缩成我能用得上的东西
```

它做的第一件事不是开讲，是问你两件事：**你现在在哪**（完全不熟 / 懂基本概念 / 相邻领域有经验）、**你要到哪**（听懂行话 / 能跟行家讨论 / 能自己动手）。

因为给 0 基础的人上高阶题，是最常见的翻车方式。

## 五步流程

| 步          | 做什么                       | 关键约束                           |
| ---------- | ------------------------- | ------------------------------ |
| **0 标定**   | 起点 + 终点 → 决定走法与题量         | 先查再问；已说过的绝不重复问；必须给选项不给开放题      |
| **1 资料检查** | 逐个读源，记录真实状态               | **未成功读取的来源不得出现在地图里**；无源时逐条标置信度 |
| **2 概念地图** | 概念 + 依赖 + 梯队              | 依赖写成 `A ← B`，出现环说明你把两个概念混成一个了  |
| **3 五个模型** | 怎么用 / 什么时候失效 / 挂在哪        | 说不出失效条件的，是口号，删掉重写              |
| **4 三组分歧** | 双方最强论证 + 裁决变量 + 被问到时的安全回答 | 强制区分**真争议**与**工程取舍**，禁止「各有优劣」  |
| **5 逐题训练** | 先建题库保覆盖，再逐题投放保适配          | 一次只出一道；答完才出下一道                 |

## 几条硬规定（它和「学习类提示词」的区别）

- **可证伪是准入门槛。** 宁可给 4 个真模型，不凑 5 个假的。
- **一次只出一道题。** 一次甩十题，人会从学习者退化成读者。
- **错误分四类，处理方式相反。** 术语错 → 一句话纠正；缺机制 → 追问；**有隐藏前提 → 升难度**；完全空白 → 直接讲，别追问（空白状态下追问只会产生羞耻感，不产生学习）。
- **追问最多两层，每层 ≤80 字。** 目的是让你自己看见漏洞，不是让你崩溃。
- **同一考点连续三次失败 → 回去改骨架。** 问题通常在结构，不在学习者。
- **台账必须落盘。** 学习是跨会话的，每次重开都等于白学一遍。

## 已知局限

- 依赖模型自身知识。无源时我会标注 `确定 / 有争议 / 不确定`，但不保证准确——这是「先能开工」的代价。
- 逐题互动，不适合「一次性交一份文档」的需求。
- 对纯操作类技能（比如某个软件按钮在哪）无效，它是为「理解」设计的，不是手册生成器。
- 「48 小时学会一个学期」这类说法是话术，不是承诺。它能压缩的是**建立结构的时间**，不能压缩你答题和犯错的时间。
